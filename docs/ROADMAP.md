# Roadmap

CofferHouse uses readiness checks instead of artificial dates. The following phases describe intended order, not promises.

## Phase 0 — Foundation

- Public repository and product specification
- CofferHouse website and public documentation
- Arc House and builder-program participation
- Final asset and collection review
- Security and disclosure framework

## Phase 1 — Scout: Read and Explain

- First Arc market adapter
- Normalized market schema
- Transparent policy engine
- Explainable risk report
- Public MVP deployment
- Bounded all-market scan and ranking
- Downloadable deterministic Scout Receipts

## Phase 2 — Scout: Monitor and Simulate

- Market monitoring
- Change alerts
- Historical observations
- Action simulation
- User-defined limits

## Phase 3 — Bounded Tools

- Explicit wallet permissions
- DCA, monitoring and research tools
- Transaction previews
- Allowlisted contracts and assets
- Member testing with controlled balances

## Phase 4 — Agent Workshop

- Agent wallet policies
- Audited execution modules
- Performance and failure reporting
- Additional research and DeFi agents

## Phase 5 — The Big Coffer

- Isolated USDC supply and borrowing markets
- Risk dashboard
- Collateral and utilization limits
- Independent security reviews
- Preferential member access subject to final rules

## Phase 6 — House DAO

- Governance proposal and treasury framework
- Progressive decentralization
- Community representation
- Automated operations only after systems are proven and monitored

## Separate ecosystem milestones

Membership collection, ascension, `$COFFERS`, rewards and distribution rules will be documented separately. None of them are required for the Scout MVP.
