# CofferHouse identity in Agent Suite

Agent Suite is presented as **The Agent Room**, a functional room inside CofferHouse rather than an unrelated finance dashboard.

## Visual roles

- `Luckiest Guy` is reserved for large product titles and agent names.
- `Gaegu` carries the child-drawn voice in navigation, explanations and labels.
- `DM Mono` remains the technical face for amounts, addresses, timestamps, checks and receipts.
- The official CofferHouse arch is the House Host. It coordinates the suite; it does not replace the individual agents or imply autonomous authority.

## Agent marks

| Agent | Mark | Meaning |
|---|---:|---|
| Scout | `⌕` | Inspect evidence |
| Opportunity | `✦` | Surface candidates |
| Strategy | `▦` | Organize bounded allocations |
| DEX | `⇄` | Compare swap and pool paths |
| Action Center | `✓` | Record the human gate |
| Guardian | `◇` | Protect the approved research intent |
| Automation | `⚙` | Test narrow revocable permissions |

The marks are lightweight interface symbols, not standalone brand logos. The official CofferHouse logo must not be redrawn.

## Product boundary

The playful wrapper must never reduce the clarity of financial evidence. Metrics, risk status, contract identity, transaction boundaries and receipts remain explicit and technical. No visual element may suggest that an observation, simulation or human acknowledgment is an executed investment.
