# QA report — 6 October 2026

Scope: CofferHouse Agent Suite release candidate on desktop, responsive layouts, keyboard access, assistive-technology semantics and public deployment.

## Automated result

- `npm test`: 181 passed, 0 failed.
- `npm run build`: successful Vite production build.
- Accessibility contract covers the skip link, named main region, inactive-room isolation, visible keyboard focus, reduced-motion handling, focus transfer and the receipt picker name.
- Existing product tests continue to cover the bounded agent flow, sealed receipts, human gates, Arc data adapters, DEX research, App Kits, durable runtime and protected endpoints.

## Browser audit

Chrome was used against the public Vercel deployment to inspect the rendered accessibility tree and layout. The audit found and the release candidate fixes:

1. Adds a keyboard-visible “Skip to main content” link.
2. Gives the main region a stable target and programmatic focus.
3. Removes every inactive Agent Suite room from the accessibility tree with `inert` and `aria-hidden`.
4. Connects each top navigation control to its destination with `aria-controls`.
5. Moves focus to the destination heading after changing rooms.
6. Adds a high-contrast focus indicator that remains visible on cream, blue, green and yellow surfaces.
7. Raises buttons and form controls to a 44 px minimum target height.
8. Names the hidden receipt-file picker for assistive technology.
9. Disables decorative motion when the operating system requests reduced motion.

## Responsive evidence

- The top room navigation remains horizontally scrollable instead of compressing labels.
- Existing breakpoints collapse Agent Hub, Scout, Opportunities, Strategy, DEX, Action Center, Guardian, Automation, Earn, Onramp and Borrow layouts into single- or two-column arrangements.
- Production build contains no duplicate element IDs in the audited Agent Hub view and no images without `alt` attributes.

## Claim boundary

Firefox, Safari and physical-device checks remain a manual release checklist item because those engines are not available in the current automated browser environment.
