## Agent directory draft

Name: CofferHouse Agent Suite

> A read-only onchain research suite combining market discovery, configurable risk policies, bounded opportunity screening, allocation research and evidence receipts. Scout, Opportunity, Strategy Lab and Guardian have distinct responsibilities within one suite. The public application helps users inspect observations and policy outcomes; it does not control funds or execute trades. Some monitoring services are protected operator features and should not be described as public APIs or user notification services.

Submission evidence to prepare:

1. Public demo and repository URLs above.
2. A documented, public read-only access path with an example request and real response. The discovery route accepts `GET /api/scout/discovery?chains=8453,1`; the permitted chain IDs are Arc `5042`, Base `8453` and Ethereum `1`. Provider availability can vary; inspect each returned network status instead of treating HTTP 200 as successful market coverage.
3. A short demo showing a market observation, policy explanation and exported receipt.
4. Clear boundaries between public access, operator authentication and unconfigured integrations.
5. An explicit financial-information notice for Agent.ai, whose public-agent policy requires appropriate disclaimers for finance-related agents.

Do not label the product MCP-compatible or A2A-compatible without an implemented and verified interface. Do not expose operator credentials to satisfy a listing check.
