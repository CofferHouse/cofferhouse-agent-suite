# Three-minute demo script

## 0:00–0:20 — One House, one Agent Room

Open the CofferHouse website and use **Enter Agent Suite**. Explain that the suite is a working room inside the broader CofferHouse product, not a separate dashboard.

Say: “CofferHouse is building member access and financial tooling on Arc. The public prototype proves the research, evidence and permission layers before custody or execution.”

## 0:20–0:55 — Scout proves the observation loop

Open Scout and point to the current Arc market count, policy profile and ranking. Select a market, show the first condition requiring attention, run a hypothetical borrow and download its simulation receipt.

Say: “The same visible policy is applied to every observation. A simulation changes projected market state only; it does not prepare or send a transaction.”

## 0:55–1:25 — Hub coordinates specialized agents

Open Agent Hub and run the read-only research sequence. Move through Opportunity and Strategy. Point out minimum liquidity, reserve, maximum allocation, diversification and review conditions.

Say: “The Hub coordinates agents; it does not collapse them into one black box. Every handoff keeps its own limits and evidence.”

## 1:25–1:55 — One human gate, then protection

Open Action Center, create an expiring approval and continue to Guardian. Show the approved-intent baseline and the allowed bounded responses. Open Automation and explain allowlists, caps, expiry, pause and revocation.

Say: “One meaningful approval records intent. Guardian and Automation cannot broaden it. The current sandbox never installs a permission or executes a transaction.”

## 1:55–2:25 — DEX and crosschain evidence

Open DEX and explain contract-first watchlists and the difference between a screening ratio and an executable quote. Then open Interop Observer and run a bounded CCTP observation window.

Say: “We do not invent pools or bridge activity. DEX research requires contract identity, and Interop Observer de-duplicates the Arc logs it actually observes.”

## 2:25–2:50 — Verify the evidence

Download one receipt, open **Verify receipt file**, and confirm it passes. Modify a sealed value in a copy and show that verification fails.

Say: “The receipt is tamper-evident: any alteration to sealed content invalidates its hash. That proves integrity, not market safety or profitability.”

## 2:50–3:00 — Close on the boundary

Return to Agent Hub.

Say: “CofferHouse Agent Suite autonomously observes, evaluates, compares, records and escalates. Humans retain financial authority. Research first; execution later.”

## Capture list

- House → Agent Suite doorway.
- Scout all-market ranking.
- Visible simulation result.
- Agent Hub sequence.
- Action Center approval and Guardian baseline.
- Automation limits.
- Interop observation receipt.
- Valid and intentionally invalid receipt verification.
